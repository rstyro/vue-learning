# vue-learning

前端菜鸟，学习 Vue 的笔记与练习。

## 目录结构

```
vue-learning/
├── vue2/            # Vue 2 学习（入门案例 + 进阶 + CSS3 练习）
├── vue3/            # Vue 3 学习（16 课完整教程，推荐新项目学习）
├── style/           # 样式资源
└── scripts/         # 验证脚本（检查 HTML 语法 / 渲染）
```

## 学习路线

1. **Vue 2 入门**（`vue2/01/`）：先通过 8 个基础案例了解 Vue 的核心概念（指令、双向绑定、组件、计算属性）
2. **Vue 3 进阶**（`vue3/`）：推荐新项目使用。打开 `vue3/index.html` 开始 16 课完整学习
   - 想快速了解 Vue2 → Vue3 差异：直接看 `vue3/04-进阶篇/5.Vue2迁移指南.html`

## 如何运行

```bash
# 直接双击 HTML 文件即可（纯本地运行）
# 或启动本地服务器
npx serve
```
