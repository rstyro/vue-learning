① v-if 基础：为 true 才渲染

💡 v-if 根据布尔值决定元素是否存在于 DOM 中：
  • 值为 true → 渲染元素
  • 值为 false → 元素直接从 DOM 移除（不是隐藏，是删除！）

  • 苹果（普通项，永远显示）
  • 橘子（普通项，永远显示）
  • 香蕉（v-if="isFruitByBanana"，为 true）
  • 西红柿（v-if="isFruitByTomato"，为 false 被移除）

💡 观察：点上面的按钮，西红柿这行是瞬间消失/出现——因为 v-if 是「增删元素」，不是 CSS 隐藏。

② v-else-if / v-else：多分支判断（像 if/else if/else）

💡 三个指令必须紧挨着使用，中间不能插入其它元素：
v-if → v-else-if → v-else

③ v-if vs v-show：什么时候用哪个？

✅ v-if 元素：为 false 时整个从 DOM 删除

✅ v-show 元素：为 false 时只是 display:none，元素还在 DOM 里

⚠️ 选择建议：
  • 频繁切换 → 用 v-show（只是切换 CSS，性能好）
  • 几乎不变 / 有 else 分支 → 用 v-if（初始不渲染，省资源）
  💡 验证方法：按 F12 打开开发者工具，在「Elements」面板里对比两种元素的显示/隐藏方式。
