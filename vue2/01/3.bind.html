🎯 v-bind 是干什么的？

💡 v-bind = 把 HTML 元素的属性 与 Vue 数据 绑定起来。
  • 数据一变，属性自动更新 —— 这就是「声明式渲染」在属性上的体现。
  • 完整写法：v-bind:属性名="数据"
  • 简写：:属性名="数据"（开发中 99% 用简写）

① 绑定 title 属性（鼠标悬停提示）

🎵 你还要我怎样 要怎样，你突然来的短信就够我悲伤

🖱 把鼠标悬停在上面这句话上，会弹出提示气泡 —— 提示内容来自 Vue 数据

绑定内容（data.message）：{{ message }}

<p v-bind:title="message">文字内容</p>
<!-- 简写形式（等价） -->
<p :title="message">文字内容</p>

② 绑定 class（对象语法：有则加，无则不加）

isHighlight 为 true 时，这一行会有黄色高亮背景（对象语法）

当前 isHighlight：{{ isHighlight }}

// 对象语法：键是类名，值是布尔（true 加类，false 不加）
<div :class="{ highlight: isHighlight }">...</div>

// 数组语法：直接放多个类名
<div :class="['base-style', isActive ? 'active' : '']">...</div>

③ 绑定 style（对象语法：动态样式）

文字颜色、大小、粗细全部是动态绑定的

当前颜色：{{ textColor }}，字号：{{ fontSize }}px，加粗：{{ isBold }}

💡 注意：style 绑定的属性名用「驼峰命名」（fontSize），因为它是 JS 对象。

④ 绑定布尔属性（disabled）

💡 disabled 是布尔属性：绑定为 false 时，Vue 会自动移除该属性，按钮恢复可点。
