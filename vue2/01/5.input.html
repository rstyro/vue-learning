🎯 v-model 是什么？

💡 v-model = 双向绑定：
  • 数据变化 → 输入框内容自动变化（数据驱动视图）
  • 用户输入 → 数据自动更新（视图驱动数据）
  • 本质是语法糖：:value="xxx" + @input="xxx = $event.target.value"
  • 不同表单元素的绑定值类型不同（见下方各示例）

① 文本输入框（input / textarea）

单行内容：{{ message }}

多行内容：{{ longText }}

② 复选框（checkbox）

单个复选框（绑定布尔值）：

是否勾选：{{ isChecked }}

复选框组（绑定数组）：

已选：{{ checkedNames }}

③ 单选按钮（radio）

选中：{{ picked }}

④ 下拉选择框（select）

单选（绑定字符串）：

选中：{{ selected }}

多选（加 multiple，绑定数组）：

选中：{{ multiSelected }}

💡 按住 Ctrl 可多选

⑤ 修饰符：.number / .trim / .lazy

v-model.number（自动转数字）： 类型：{{ typeof age }}

v-model.trim（去除首尾空格）： 值：[{{ trimText }}]

v-model.lazy（改为 change 事件触发，光标离开才更新）： 值：{{ lazyText }}

⚠️ 初始值类型很重要：
  • 单选/多选 select、多选框组 → data 里初始化为 []（数组）
  • 单选 radio、单个 checkbox、普通 input → 初始化为字符串 / 布尔值
  • 否则界面可能不会按预期初始化（比如 radio 初始是数组会选不中）
