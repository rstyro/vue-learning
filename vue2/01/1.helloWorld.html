① {{ }} 插值语法

💡 Vue 的核心思想：声明式渲染。你只关心「数据是什么样」，Vue 帮你更新「页面是什么样」。

问候语：{{ message }}

反转后的问候语：{{ message.split('').reverse().join('') }}（插值里可以写简单的 JS 表达式）

② 三种输出方式：{{ }} 插值 / v-text / v-html

💡 区别：
  • {{ }}：输出纯文本，HTML 标签会被转义（安全，推荐）
  • v-text：与插值等价，但不会闪烁
  • v-html：渲染真正的 HTML（⚠️ 只能用于可信内容，防止 XSS 攻击）
