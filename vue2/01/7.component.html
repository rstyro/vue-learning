🎯 什么是组件？

💡 组件 = 可复用的代码块。把页面拆成一个个小积木，每个积木负责自己的部分。
  • Vue.component('组件名', { 配置 }) 定义全局组件
  • 组件就像自定义 HTML 标签：<fruit-item></fruit-item>
  • 父组件通过 props 给子组件传数据（父→子，单向）
  • 子组件通过 emit / @事件 通知父组件（子→父）

💡 三个按钮互不影响 —— 每个组件实例都有自己独立的 data。
⚠️ 注意：组件里 data 必须写成函数（返回对象），不能写对象！
否则所有实例会共享同一份数据（这是 Vue 2 的重要规范）。

③ props 进阶：写成对象可以校验类型、设默认值

Vue.component('user-badge', {
    props: {
        name:  { type: String, required: true },   // 必填字符串
        level: { type: Number, default: 1 }         // 可选，默认 1
    },
    template: '<span>👤 {{ name }}（Lv.{{ level }}）</span>'
});

④ 子组件给父组件传值（$emit）

父组件收到的消息：{{ childMsg }}

// 子组件：点击按钮时 $emit('send', '数据') 向外发事件和值
Vue.component('child-sender', {
    template: '<button @click="$emit(\'send\', \'来自子组件的数据!\')">点我发送</button>'
});

// 父组件：@send="childMsg = $event" 接收（$event 就是子组件传来的值）
<child-sender @send="childMsg = $event"></child-sender>
⚠️ 核心原则：单向数据流 —— 子组件不能直接改 props，只能通过 $emit 通知父组件改。
