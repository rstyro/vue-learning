🎯 v-on 是干什么的？

💡 v-on = 监听 DOM 事件，触发时执行对应逻辑。
  • 完整写法：v-on:click="方法"
  • 简写：@click="方法"（开发中 99% 用简写）
  • 事件方法写在 methods 选项里，用 this.xxx 访问数据

① 点击事件：反转字符串

🎵 你还要我怎样 要怎样，你突然来的短信就够我悲伤

💡 每次点击按钮，都会把 message 反转（"你是年少的欢喜" → "喜欢的少年是你是你"）。
注意鼠标悬停歌词时弹出的提示，它来自 v-bind:title（上一课的内容，这里配合使用）。

// 完整写法 v-on:click
<button v-on:click="reverseMessage">{{ message }}</button>

// 简写 @click（等价，推荐）
<button @click="reverseMessage">{{ message }}</button>

② 事件传参 + 访问原生事件对象

当前计数：{{ count }}

最近一次点击的坐标：{{ lastClickInfo }}

// $event 代表原生 DOM 事件对象（注意顺序：先普通参数，再 $event）
<button @click="addCount(3, $event)">+3</button>

methods: {
    addCount: function (n, event) {
        this.count += n;
        this.lastClickInfo = event.clientX + ', ' + event.clientY;
    }
}
