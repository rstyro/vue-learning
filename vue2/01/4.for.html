🎯 v-for 是干什么的？

💡 v-for = 遍历数组 / 对象，为每一项渲染一个元素（列表渲染）。
  • 语法：v-for="item in 数组" 或 v-for="(item, index) in 数组"
  • 对象的写法：v-for="(value, key, index) in 对象"
  • ⚠️ 遍历列表时必须写 :key（唯一标识，帮助 Vue 精准复用和更新 DOM）

① 遍历数组（带索引）：人生各年龄段的雅称

  • {{ index + 1 }}. {{ item }} 
<li v-for="(item, index) in items" :key="index">
    {{ index + 1 }}. {{ item }}
</li>

② 遍历对象数组：年龄雅称对照表

序号年龄雅称
{{ index + 1 }} {{ item.age }} {{ item.alias }}

当前共 {{ obj.length }} 条记录（数组末尾的「new add」是创建 Vue 实例后动态 push 进去的）

③ 遍历对象本身（value / key / index）

  • {{ index }}. {{ key }} = {{ value }} 
<li v-for="(value, key, index) in person" :key="key">...</li>

④ 动态增删列表（响应式数组方法）

  • {{ item.name }}
⚠️ 响应式数组方法：Vue 2 中能触发更新的方法有 7 个：
push / pop / shift / unshift / splice / sort / reverse
  • 直接用下标改 arr[0] = xxx 不会触发更新（要用 Vue.set）
  • 直接改 length 也不会触发更新

⑤ v-for 与 v-if 同时使用（⚠️ 注意优先级）

只显示名字长度 >= 3 的水果：

  • {{ fruit }}（长度 {{ fruit.length }}）

💡 Vue 2 中 v-for 优先级高于 v-if（先循环再判断），性能略差。
Vue 3 中 v-if 优先级高于 v-for（不能再访问 item），需注意写法差异。
✅ 最佳实践：用 computed 先过滤，再 v-for 渲染。
