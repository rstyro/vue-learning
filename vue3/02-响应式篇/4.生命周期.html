🎯 什么是生命周期钩子？

💡 一个组件从「创建 → 挂载到页面 → 更新 → 销毁」就像一个人的一生，
在每个关键时刻，Vue 会调用你预先注册的钩子函数，让你能插入自己的逻辑（比如初始化数据、清理定时器）。

📋 生命周期总览（Vue 3 组合式 API 版本）

钩子函数触发时机典型用途
onBeforeMount挂载 DOM 前准备工作
onMounted挂载完成后（DOM 可用）⭐ 发请求、操作 DOM、初始化第三方库
onBeforeUpdate数据变化、重新渲染前更新前保存状态
onUpdated重新渲染后DOM 已更新
onBeforeUnmount卸载前清理准备
onUnmounted卸载后⭐ 清理定时器、解绑事件、取消请求

💡 还有两个常用的：onBeforeMount 之前的 onBeforeCreate / onCreated（选项式 API 用，组合式里用 setup 代替），以及 onActivated / onDeactivated（配合 KeepAlive，进阶篇会讲）。
setup() 本身就是「创建阶段」：ref 定义、方法定义都发生在 setup 里。

📖 代码：子组件的生命周期（完整源码）

// 子组件：Child
setup() {
    const childCount = ref(0);

    onBeforeMount(() => log('beforeMount：挂载前'));
    onMounted(() => log('mounted：✅ 已挂载，DOM 可用，可以发请求了'));
    onBeforeUpdate(() => log('beforeUpdate：数据变了，重新渲染前'));
    onUpdated(() => log('updated：重新渲染完成'));
    onBeforeUnmount(() => log('beforeUnmount：卸载前，清理资源'));
    onUnmounted(() => log('unmounted：❌ 已卸载，定时器记得清掉'));

    return { childCount };
}

② 真实场景演练：定时器 + 数据加载

💡 最常见的组合：
  • onMounted 里：启动定时器 / 发请求（此时页面已渲染，操作 DOM 安全）
  • onUnmounted 里：清理定时器（否则组件销毁后定时器还在跑 → 内存泄漏！）
