🎯 什么是计算属性 computed？

💡 计算属性 = 根据已有数据「推导」出新数据，并且自动缓存。
  • 依赖的数据没变 → 直接返回缓存结果，不重新计算（性能好）
  • 依赖的数据变了 → 自动重新计算，页面自动更新
  • 对比 methods：methods 每次调用都重新执行；computed 有缓存。

① 基本用法：全名拼接（computed vs methods 对比）

姓：

名：

用 computed 计算的全名：{{ fullName }}

用 methods 调用的全名：{{ getFullName() }}（每次调用都执行函数）

⏱ 统计：computed 执行了 {{ computedCount }} 次（带缓存，只有依赖变化才 +1）
      methods 执行了 {{ methodCount }} 次（每次渲染都会 +1）

② 经典场景：购物车总价（computed 依赖多个数据）

商品单价数量小计
{{ item.name }} ￥{{ item.price }} {{ item.quantity }} ￥{{ item.price * item.quantity }}

商品总数：{{ totalCount }} 件

合计金额：￥{{ totalPrice }}

💡 totalCount 和 totalPrice 都是 computed：只要购物车里任何数量变化，它们自动更新。

③ 经典场景：搜索筛选列表（computed 依赖输入框）

共 {{ filteredStudents.length }} 个结果

  • {{ s.name }} - {{ s.score }} 分

💡 这里不能在原数组上 filter（会破坏原数据），而是用一个 computed 返回「过滤后的新数组」。

④ 进阶：可写 computed（getter + setter）

把 firstName 和 lastName 合起来，还能通过 fullName2 = '新名字' 反推拆分写回！

当前 fullName2 = {{ fullName2 }}

姓 = {{ firstName2 }}，名 = {{ lastName2 }}（你修改全名时，setter 会把名字拆开写回）

const fullName2 = computed({
    get: () => firstName2.value + ' ' + lastName2.value,  // 读取时
    set: (val) => {                                       // 赋值时
        [firstName2.value, lastName2.value] = val.split(' ');
    }
});
