🎯 本课核心：响应式到底是什么？

💡 响应式 = 数据变了，用到它的地方自动更新，你不需要手动操作 DOM。
Vue 3 提供两个创建响应式数据的核心 API：ref（推荐，全能）和 reactive（对象专用）。

① ref —— 推荐首选（基本类型 + 对象都能用）

👤 名字：

🎂 年龄：{{ age }}

📦 一个 ref 包装的「对象」也可以：{{ user.name }}，{{ user.age }} 岁

💡 ref 使用要点：
  1️⃣ 在 JS 代码中必须用 .value 读写（name.value = '张三'）
  2️⃣ 在模板（HTML）中不需要 .value，Vue 会自动解包
  3️⃣ 就算包装的是对象，改对象内部属性也会触发更新（内部自动用了 reactive）

const name = ref('小明');
name.value = '小红';      // JS 里必须 .value
<p>{{ name }}</p>   // 模板里不用 .value

② reactive —— 只能包「对象」，直接访问属性

📚 学习进度：{{ study }}

已完成：{{ finishedCount }} / {{ courseCount }}

💡 reactive 使用要点：
  1️⃣ 只接受对象（数组也可以），不接受 string / number 等基本类型
  2️⃣ JS 中直接访问属性，不需要 .value
  3️⃣ 重新赋值整个对象会丢失响应性（后面「响应式进阶」篇讲解决方案 toRefs）

const study = reactive({ finished: 2, courseCount: 5 });
study.finished++;     // 直接访问，无需 .value

③ ref vs reactive：选择建议 & reactive 解构陷阱

✅ ref（推荐日常使用）

  • 基本类型、对象都能包
  • 从函数返回值时自动解包
  • 解构不丢失响应性
  • 团队约定：全项目统一用 ref，心智负担小

⚠️ reactive（适合嵌套深的对象）

  • 只能包对象/数组
  • 直接访问属性，无 .value
  • 解构会丢失响应性（大坑！）
  • reactive 里嵌套的对象属性响应式更深
🔥 reactive 解构陷阱演示：下面用普通解构取出的 countA 不响应；必须用 toRefs() 包装后解构才响应。
计数器（原始对象）：{{ state.count }}
解构出的 countA：{{ countA }}
用 toRefs 解构出的 countB：{{ countB }}
