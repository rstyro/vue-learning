🎯 组件通信全景图

💡 上一课讲了 props（父→子）和 emit（子→父）。但现实中组件可能隔了多层，于是 Vue 还提供了：
  1️⃣ v-model 组件——自定义「双向绑定」的组件
  2️⃣ defineExpose——父组件直接调用子组件的方法
  3️⃣ provide / inject——祖孙之间跨层传数据
  4️⃣ 全局状态管理（Pinia）——任意组件共享数据（后面章节介绍）

① v-model 自定义组件：把「显示值 + 改值事件」打包成双向绑定

温度计组件（自定义 v-model 组件）

父组件维护的温度：{{ temp }} ℃

💡 组件上使用 v-model="temp" 等价于：
<temp-meter :model-value="temp" @update:model-value="temp = $event" />
子组件内部：接收 props.modelValue，点击按钮时 emit('update:modelValue', 新值)

② defineExpose：父组件调用子组件的内部方法

倒计时器组件（父组件调用子组件方法）

💡 步骤：
  1️⃣ 子组件把方法暴露出来（单文件组件用 defineExpose({ start, reset })；本页纯 JS 环境下 setup return 出去即可）
  2️⃣ 父组件给子组件加 ref="名字"
  3️⃣ 父组件通过 refs.名字.start() 调用
  ⚠️ 注意：在 <script setup> 中，子组件必须显式 defineExpose，父组件才能访问到内部的东西

③ provide / inject：跨层传递（爷爷直接给孙子）

🌳 组件树：爷爷 → 爸爸 → 孙子

👴 爷爷组件（provide 提供 theme 和 user）
👨 爸爸组件（什么都不用做，只管传递）
👦 孙子组件（inject 注入使用）

🎨 主题：{{ theme }}
👤 用户：{{ user.name }}（{{ user.age }} 岁）

💡 provide/inject 专门解决「跨层传递」：爷爷直接给孙子，中间层（爸爸）不用管。
  • provide('key', 值)：祖先提供
  • inject('key')：后代接收
  • 适合：主题、用户信息、全局配置等「贯穿整个组件树」的数据
