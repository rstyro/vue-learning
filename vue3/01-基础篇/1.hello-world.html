① {{ }} 插值语法

💡 Vue 的核心思想：声明式渲染。你只关心「数据是什么样」，Vue 帮你更新「页面是什么样」。

问候语：{{ message }}

反转后的问候语：{{ message.split('').reverse().join('') }}（插值里可以写简单的 JS 表达式）

当前时间戳：{{ Date.now() }}

② v-model 双向绑定

💡 v-model 让「页面输入」和「数据」保持同步：改了输入框，message 也跟着变！

你输入的内容实时显示在这里：{{ message }}

③ v-on:click（@click）事件

💡 @click 是 v-on:click 的简写，用来监听 DOM 事件。

点击次数：{{ count }}

④ v-if 条件渲染

💡 v-if 为 true 才渲染元素，false 则直接从 DOM 中移除。

⑤ v-for 列表渲染

💡 v-for 遍历数组渲染列表，记得写 :key（唯一标识，帮助 Vue 高效更新）。

  • {{ index + 1 }}. {{ tech }} —— 长度：{{ tech.length }}
