两个应用：同样功能，两种写法

💡 Vue 3 支持两种 API 风格，效果完全一样：
  • 选项式 API（Options API）：Vue 2 老写法，靠 data / methods / computed / watch 等「选项」组织代码
  • 组合式 API（Composition API）：Vue 3 新写法，靠 setup() 函数 + 逻辑复用，推荐学习

🅰 左侧：选项式 API（Vue 2 兼容写法）

🧮 计数器：{{ counter }}

🔢 翻倍结果（computed）：{{ doubleCounter }}

⏱ 日志（watch 监听 counter）：{{ history }}

🅱 右侧：组合式 API（Vue 3 推荐写法）

🧮 计数器：{{ counter }}

🔢 翻倍结果（computed）：{{ doubleCounter }}

⏱ 日志（watch 监听 counter）：{{ history }}

💡 两个应用长一模一样，但代码组织方式完全不同，看下面的源码对比！

📖 源码对比：同一逻辑的两种组织方式

// 写法一：选项式（Vue 2 风格）
const { createApp } = Vue;
createApp({
    data() {
        return { counter: 0, history: '' };
    },
    computed: {
        doubleCounter() { return this.counter * 2; }
    },
    watch: {
        counter(newVal) { this.history = '值变为 ' + newVal + ' | ' + this.history; }
    },
    methods: {
        increment() { this.counter++; }
    }
}).mount('#app-options');

// 写法二：组合式（Vue 3 推荐）——所有逻辑写在一个 setup() 里
const { createApp, ref, computed, watch } = Vue;
createApp({
    setup() {
        const counter = ref(0);
        const history = ref('');

        const doubleCounter = computed(() => counter.value * 2);

        watch(counter, (newVal) => {
            history.value = '值变为 ' + newVal + ' | ' + history.value;
        });

        function increment() { counter.value++; }

        return { counter, history, doubleCounter, increment };
    }
}).mount('#app-composition');

🎯 组合式 API 的核心价值：按「逻辑功能」组织代码，而不是按「选项类型」组织。
当组件变复杂时（比如同时有搜索、筛选、分页、排序），选项式会把这些逻辑拆散在 data/methods/watch 各处； 组合式可以把每个功能的所有代码放在一起，甚至抽成可复用的函数（后面「组合式函数」章节会讲）。
