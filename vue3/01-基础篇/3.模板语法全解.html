1️⃣ 插值 {{ }} 与 v-html

① 文本插值（{{ }}）—— 输出纯文本，HTML 标签会被转义，防止 XSS 攻击

{{ rawHtml }}

② v-html —— 渲染真正的 HTML（⚠️ 只能用于可信内容，不要用于用户输入！）

💡 对比：上面是转义后的「文本」，下面是真正渲染的「HTML」。

2️⃣ v-bind（简写 :）—— 属性绑定

① 绑定普通属性

图片地址来自 data：{{ imgSrc }}

② 绑定 class（对象语法：有则加，无则不加）

isActive 为 true 时，这一行会有黄色背景（对象语法）

③ 绑定 style（对象语法）

文字颜色和大小都是动态绑定的

④ 绑定布尔属性（disabled）—— false 时会自动移除该属性

3️⃣ v-on（简写 @）—— 事件监听

① 基本用法 + 传参

当前计数值：{{ count }}

② 事件修饰符（.prevent 阻止默认行为 .stop 阻止冒泡）

最后提交的名字：{{ submittedName }}

③ 按键修饰符（@keyup.enter 回车触发）

{{ enterMsg }}

4️⃣ v-if / v-else-if / v-else —— 条件渲染

（输入 0-100 的成绩）

🅰 优秀！成绩 >= 90

🅱 及格！成绩 60-89

❌ 不及格！成绩 < 60

💡 v-if 是「真删除」：条件为 false 时元素直接从 DOM 移除。
对比 v-show：它只是 CSS 的 display:none，元素还在 DOM 里。
频繁切换用 v-show，几乎不变的条件用 v-if。

5️⃣ v-for —— 列表渲染

① 遍历数组（带索引）

  • {{ i }} - {{ fruit }}

② 遍历对象（值 / 键 / 索引）

  • {{ index }}. {{ key }} = {{ value }}

③ 遍历数字范围

{{ n }}

④ 动态增删列表（:key 的重要性）

  • {{ item.name }}

6️⃣ v-model —— 双向绑定

① 文本输入框

→ {{ text1 }}

② 多行文本 textarea

→ {{ text2 }}

③ 复选框（单个：绑定布尔值）

是否勾选：{{ isChecked }}

④ 复选框组（多个：绑定数组）

篮球 足球 游泳 → 已选：{{ hobbies }}

⑤ 单选按钮

男 女 → {{ gender }}

⑥ 下拉选择框

→ {{ city }}

⑦ 修饰符：.number（转数字）和 .trim（去首尾空格）

→ 类型是：{{ typeof age }} → [{{ trimText }}]

💡 v-model 的本质是「语法糖」：等价于 :value="xxx" + @input="xxx = $event.target.value"。
在组件上使用 v-model 时等价于 :modelValue + @update:modelValue（后面组件篇会讲）。
