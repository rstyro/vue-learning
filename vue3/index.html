🚀 Vue 3 学习之旅

从零开始，循序渐进 —— 按编号顺序学习，每一课都是可运行的实例

📌 使用说明

每个 HTML 文件都是一个可独立运行的教学实例：

1️⃣ 双击 HTML 文件用浏览器打开（学习用 vue.global.js，无需安装任何东西）
2️⃣ 或者启动本地服务器：npx serve vue3 或 python -m http.server
3️⃣ 每个页面都有「💡 知识点讲解 + 🖱 可操作演示 + 📖 源码注释」

⚠️ 建议打开浏览器控制台（F12），很多课程在控制台打印了额外的提示信息。

📚 第一部分：基础篇

认识 Vue 3，学会模板语法和两种代码风格
第1课Hello World：第一个 Vue 3 应用（插值/v-model/@click/v-if/v-for/:class） 第2课选项式 API vs 组合式 API：两种风格对比 第3课模板语法全解：v-bind / v-on / v-if / v-for / v-model

🔁 第二部分：响应式篇

Vue 3 的核心灵魂 —— 数据驱动视图
第4课ref 与 reactive：响应式数据（含解构陷阱） 第5课computed 计算属性：缓存与推导（含可写 computed） 第6课watch 侦听器：deep / immediate / watchEffect / 停止监听 第7课生命周期钩子：onMounted / onUnmounted 实战

🧩 第三部分：组件篇

把页面拆成积木 —— 组件化开发
第8课组件基础：props（父传子）与 emit（子传父） 第9课插槽 slot：默认插槽 / 具名插槽 / 作用域插槽 第10课组件通信进阶：v-model / defineExpose / provide-inject 第11课动态组件 component :is 与 KeepAlive 缓存

🚀 第四部分：进阶篇

写真正生产级 Vue 3 代码需要的进阶知识
第12课组合式函数 Composables：useCounter / useMouse / useLocalStorage 第13课响应式进阶：toRefs / readonly / shallowRef / customRef 第14课内置组件：Teleport 传送 / Transition 过渡动画 第15课自定义指令：自动聚焦 / v-color / 点击外部关闭 / 权限指令 第16课Vue2 老司机迁移指南：差异速查 + 心法总结

🎯 学习建议

💡 动手优先：每个例子都打开源码（Ctrl+U），改一改数据，看看页面变化
💡 对比记忆：第2课选项式 vs 组合式、第4课 ref vs reactive，反复对比
💡 学完记得复习：第16课迁移指南是「回头检验」你掌握程度的最佳工具
💡 进阶方向：学完本目录后，可以继续学习 Vue Router（路由）、Pinia（状态管理）、Vite（工程化）
