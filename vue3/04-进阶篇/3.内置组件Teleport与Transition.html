🎯 本课内容：两个好用的内置组件

💡 Vue 3 内置了几个特殊组件，直接可用：
  • <Teleport>：把内容「传送」到页面的其它位置（比如 body）渲染
  • <Transition>：给元素的显示/隐藏添加过渡动画
  • 还有 <TransitionGroup>（列表动画）、<KeepAlive>（已学过）、<Suspense>（异步组件）

💡 Teleport 的经典使用场景：
  • 弹窗 / 对话框 / 抽屉：避免被父级 overflow 或 z-index 影响
  • 全局提示（toast / notification）
  • 全屏遮罩、模态框

    • 💡 Transition 的核心是「CSS 类约定」：
      • xxx-enter-from：进入前的初始状态
      • xxx-enter-active：进入过程中的过渡属性
      • xxx-enter-to：进入后的结束状态（一般省略，默认是元素本来样式）
      • 离开同理：xxx-leave-from / leave-active / leave-to
      • 只要 CSS 类名写对，Vue 自动帮你切换，无需 JS 动画代码！
