💡 如果你已经学过 01/ 目录里的 Vue 2 教程（选项式 API、v-if、v-for、computed、watch...），
这篇文章帮你把 Vue 2 的知识点一一映射到 Vue 3 —— 大部分语法一模一样，只有几个关键差异。

🔍 关键差异逐个看

① 创建应用方式不同（最直观的变化）

Vue 2Vue 3
new Vue({
    el: '#app',
    data: { msg: 'hi' }
})
 
const app = createApp({
    setup() {
        const msg = ref('hi')
        return { msg }
    }
})
app.mount('#app')

💡 Vue 3 的 createApp 返回一个独立的 app 实例。
好处：同一个页面可以创建多个互不干扰的应用；组件/指令注册在 app 上，不再污染全局。

② data 必须写成函数

⚠️ Vue 2 也推荐 data 写成函数，Vue 3 是强制：
data: { count: 0 }（Vue2 允许，但会造成多个实例共享数据）
data() { return { count: 0 } }（Vue3 唯一写法，每个实例独立）

③ 生命周期钩子重命名

Vue 2Vue 3 选项式Vue 3 组合式
beforeCreatebeforeCreatesetup()
createdcreatedsetup()
beforeMountbeforeMountonBeforeMount
mountedmountedonMounted
beforeUpdatebeforeUpdateonBeforeUpdate
updatedupdatedonUpdated
beforeDestroybeforeUnmountonBeforeUnmount
destroyedunmountedonUnmounted

⚠️ 两个最容易踩的坑：beforeDestroy → beforeUnmount、destroyed → unmounted

④ 自定义事件的变化

Vue 2：子组件 this.$emit('change', data)，父组件 @change 监听。
Vue 3：用法相同，但事件名不再自动转成中划线，建议统一用 camelCase：
this.$emit('update:modelValue', data) 配 @update:model-value（模板里两种都能用）。

⑤ v-model 在组件上的变化（重要！）

Vue 2 组件上的 v-model 固定用 value 属性和 input 事件：
<my-input v-model="x" /> = <my-input :value="x" @input="x=$event" />

Vue 3 改成 modelValue 和 update:modelValue：
<my-input v-model="x" /> = <my-input :modelValue="x" @update:modelValue="x=$event" />
并且支持多个 v-model：v-model:title、v-model:content 可以同时用！

⑥ 过滤器 filter 被移除

🔥 Vue 2 的 filters: { format() {...} } 在 Vue 3 中不再支持。
替代方案： 

// 方法一：全局函数
function formatPrice(v) { return '￥' + v.toFixed(2); }
<span>{{ formatPrice(price) }}</span>

// 方法二：computed（推荐，自动缓存）
const formattedPrice = computed(() => '￥' + price.value.toFixed(2));

⑦ 模板可以多根节点了

Vue 2：组件模板必须包一层根元素（<div>...</div>）
Vue 3：直接并列写多个根元素，自动用 Fragment 包裹，DOM 更干净：

// Vue 3 合法模板：两个根节点
<h1>标题</h1>
<p>正文</p>

🧠 迁移心法总结

1️⃣ 模板语法 90% 兼容：v-if / v-for / v-model / @click / :class 完全一样
2️⃣ 选项式 API 还能用：Vue 3 完全支持 Vue 2 的写法，只是底层换了
3️⃣ 新项目推荐直接学组合式 API：它不是必须，但它是 Vue 3 的灵魂
4️⃣ 先跑起来再优化：老项目迁移可以先只升版本，再逐步重构
5️⃣ 遇到报错先看控制台：Vue 3 的错误提示比 Vue 2 清晰很多
