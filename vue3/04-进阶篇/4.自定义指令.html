🎯 什么是自定义指令？

💡 指令（directive）= 给元素附加行为的「v-xxx 标签」。
  • Vue 内置了 v-model、v-show、v-if 等
  • 自定义指令让你把「对 DOM 的操作」封装起来复用：
    比如「自动聚焦」「点击外部关闭」「输入框限制数字」「水印」
  • 语法：vFocus 对应指令名 focus，使用时写作 v-focus

① 最简单的自定义指令：自动聚焦

页面加载后，下面这个输入框会自动获得焦点（不需要点它）：

💡 核心代码：
app.directive('focus', { mounted: (el) => el.focus() })
指令的钩子函数第一个参数 el 就是「绑定了指令的元素」。

② 带参数的指令：指令值 + 修改属性

v-color：把文字变成指定颜色

我是红色（v-color="'red'"）

我是蓝色（v-color="'blue'"）

我是绿色（v-color="'#42b983'"）

我是动态颜色的文字

v-rainbow：动态颜色的文字（新值变化时更新）

💡 指令的核心钩子：
  • mounted(el, binding)：元素挂载时执行一次
  • updated(el, binding)：指令的值变化时执行
  • binding.value：拿到 v-color="xxx" 传入的值

app.directive('color', {
    mounted(el, binding) {
        el.style.color = binding.value;   // 挂载时设置颜色
    },
    updated(el, binding) {
        el.style.color = binding.value;   // 值变化时更新颜色
    }
});

// v-click-outside：点击元素外部时触发
app.directive('click-outside', {
    mounted(el, binding) {
        // ⚠️ 延迟注册：立即注册会让"打开下拉的那次点击"冒泡时误触发关闭
        setTimeout(() => {
            if (!el.isConnected) return;   // 下拉已卸载则跳过
            el.__clickOutsideHandler__ = (e) => {
                // 如果点击目标不在元素内部，则执行绑定的函数
                if (!(el === e.target || el.contains(e.target))) {
                    binding.value();
                }
            };
            document.addEventListener('click', el.__clickOutsideHandler__);
        }, 0);
    },
    unmounted(el) {
        // 记得清理事件监听，防止内存泄漏
        document.removeEventListener('click', el.__clickOutsideHandler__);
    }
});

④ 权限指令 v-permission：无权限的元素直接隐藏（实战！）

用户角色：{{ role }}

🔒 只有 admin 才能看到这个删除按钮

🔒 只有 admin 才能看到的配置面板

✅ 所有人都能看到这行普通内容

💡 思路：指令里判断「当前用户角色」是否在允许列表里，
没有权限就 el.remove() 把元素从 DOM 移除。
真实项目里常结合 Pinia 里的用户信息来判断。

app.directive('permission', {
    mounted(el, binding) {
        // 模拟从 store 获取当前角色（真实项目从 Pinia 拿）
        const role = getCurrentRole();
        const required = binding.value;   // v-permission="'admin'" 的值
        if (role !== required) {
            el.parentNode && el.parentNode.removeChild(el);
        }
    }
});
