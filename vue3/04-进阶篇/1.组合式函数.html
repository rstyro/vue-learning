🎯 什么是组合式函数？

💡 组合式函数（Composable）= 用「函数」把一段「带状态的逻辑」封装起来，到处复用。
  • 命名规范：以 use 开头（如 useCounter、useMouse、useFetch）
  • 函数里可以用 ref / computed / watch / 生命周期 —— 它和组件里的 setup 一样能干任何事
  • 本质：它就是 Vue 版的「自定义 Hook」（React 的 custom hook 概念一样）
  • 好处：多个组件共享同一段逻辑，改一处、处处生效

① 经典例子：useCounter 计数器

🅰 计数器 1

数值：{{ c1.count }}（{{ c1.count >= 10 ? '达到10啦！' : '继续加油' }}）

🅱 计数器 2（同一逻辑，独立状态）

数值：{{ c2.count }}

💡 两个计数器用的是同一个函数，但各自独立计数——组合式函数每次调用都创建「新的一份」状态。

// 定义一个组合式函数（通常单独放一个 js 文件）
function useCounter(initial = 0) {
    const count = ref(initial);           // 状态
    const isOverTen = computed(() => count.value >= 10);  // 派生状态
    function increment() { count.value++; }  // 方法
    function decrement() { count.value--; }
    function reset() { count.value = initial; }
    return { count, isOverTen, increment, decrement, reset };  // 返回出去
}

// 组件里使用（想用几次用几次）
const c1 = useCounter(0);
const c2 = useCounter(100);

② 经典例子：useMouse 鼠标位置（含事件绑定与清理）

🖱 在下面这块区域里移动鼠标：

坐标：X = {{ mouse.x }}，Y = {{ mouse.y }}

💡 useMouse 内部：
  • onMounted 里给 window 绑定 mousemove 事件
  • onUnmounted 里移除事件（必须清理！否则组件销毁后监听器还挂着，浪费内存甚至报错）
  这就是「组合式函数」比普通工具函数强的地方：它和组件的生命周期融为一体。

function useMouse() {
    const x = ref(0);
    const y = ref(0);

    function update(e) { x.value = e.clientX; y.value = e.clientY; }

    onMounted(() => window.addEventListener('mousemove', update));
    onUnmounted(() => window.removeEventListener('mousemove', update));

    return { x, y };
}

③ 进阶例子：useLocalStorage（数据自动同步到本地存储）

📌 原理：useLocalStorage 内部用 watch 监听数据，变化时自动写入 localStorage。
🔄 现在刷新页面试试——数据不会丢！

// 通用组合式函数：任何「需要持久化」的数据都能用它
function useLocalStorage(key, initial) {
    // 初始值：优先从 localStorage 读，读不到用传入的初始值
    const data = ref(JSON.parse(localStorage.getItem(key)) ?? initial);

    // 深度监听 data，变化就写入 localStorage
    watch(data, (val) => localStorage.setItem(key, JSON.stringify(val)), { deep: true });

    return data;
}

// 使用：一行代码获得「带持久化」的响应式数据
const settings = useLocalStorage('my-settings', { username: '游客', theme: 'light' });

④ 组合式函数 vs mixins（Vue 2 时代）

对比项mixins（Vue2）组合式函数（Vue3）
数据来源是否清晰❌ 不知哪个 mixin 提供✅ 从函数返回，一目了然
命名冲突❌ 多个 mixin 同名属性互相覆盖✅ 可以解构重命名
传参❌ 无法传参✅ useCounter(100) 随意传参
复用粒度❌ 整个 mixin 全量合并✅ 想用哪个函数用哪个

🎯 结论：Vue 3 官方推荐用组合式函数替代 mixins，这是组合式 API 的最大价值！
